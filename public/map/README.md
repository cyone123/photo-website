# 地球底图

`land.geojson`: Natural Earth 1:110m land polygons, public domain.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

License: https://www.naturalearthdata.com/about/terms-of-use/

The globe uses land outlines only, without administrative boundaries. This file is served locally; the visitor's browser does not request third-party map tiles.
